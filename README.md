# 西蒙学习法 Skill

把「我想学 X」变成一张带工时预算、阶段划分、验收标准的方案。

## 这是什么

一套六阶段的执行流程，从《西蒙学习法：如何在短时间内快速学会新知识》（友荣方略著，人民邮电出版社 2022.9）重排而来。

**不是读书笔记。** 原书 48 节是并列结构，可以任意抽走而不损失；本 skill 把它重排成有依赖关系的串联流程（S0→S6），每阶段带一道闸门，并补上了原书缺的两样东西——**工时估算式**和**收敛判据**。

## 核心内容

### 六阶段

| 阶段 | 做什么 | 闸门 |
|---|---|---|
| **S0** 三要素体检 | 动机 / 方法 / 时间，任一项为空就停 | 三项各写一句话 |
| **S1** 选领域 | 2–3 候选 → 四维打分 → 知识四类定位 → 信息源校验 | 能说出"为什么不是 B/C" |
| **S2** 定目标 | 期望−现状 → SMART 五关 → 反算工时 → 写达成标志 | 第三人能不追问就判断达成 |
| **S3** 拆组块 | 定范围 → 选切入点 → 卡 15 分钟粒度 → 标 20% → 排优先级 | 组块数 × 单组块工时 ≤ 额度 |
| **S4** 集中攻 | 锥子三要素 → 习惯四要素 → 断点续传 → 主动走神 | 有具体时段 + 具体组块编号 |
| **S5** 记与练 | 8 个复习点 → 两头加重 → 练习 ≥ 学习 × 3 | 练习占比 ≥ 75% |
| **S6** 验真伪 | 三区定位 → 四档定位 → 搭/抽积木 → 陌生场景测试 | 陌生场景能跑通 |

### 最硬的一块：工时估算

原书给了两个互相矛盾的数字（1.5 分钟/组块 vs 15 分钟/组块，差 10 倍）。解开之后是：

```
T_知道 = N × 1.5 分钟      →  一门学问 = 1,250 小时（5.2 个月，每天 8h）
T_会用 = N × 15 分钟       →  一门学问 = 12,500 小时（6.25 年）
```

两条完全独立的路径（组块模型 / 721 法则反推）收敛到同一个数。

**这解释了「短时间学会」到底短到什么程度**：刘谦 21 小时弹会一首曲子，和 12,500 小时学会一门学问，不矛盾——差别在于**目标粒度**，不在于效率。所谓速成，真正起作用的机制是把目标压到足够小，不是单位时间产出提高十倍。

## 怎么用

**做方案**：复制 `assets/学习方案模板.md`，从 S0 往下填。卡在哪一关查 `references/02` 对应的分支处理。

**只要一个数**：拿 `references/03` 的分级表，找到你的目标粒度，看 T_会用 那一列。然后和你实际能投入的时间比。

**诊断"学了很久没效果"**：直接跳到 S6。先做三区定位（是不是一直在舒适区打转），再做四档定位（是不是停在"记"档），最后做陌生场景测试。

**判断"该学什么"**：只走 S1，后面全部跳过。

## 三条最容易踩的坑

1. **把"5.2 个月"当成"每天半小时坚持半年"。** 原书那个数前提是每天 8 小时不间断。
2. **把"知道"当"会用"交付。** 两者工时差 10 倍。计划按"知道"排，验收按"会用"验，必然失败。
3. **跳过 S1 直接在 S3/S4 做功。** 表现是"每天学得很满，但说不出为什么学这些"。原书的公式用加法连接四步，容易让人误以为可以互补；实际是串联，短板决定上限。

## 与原书的 9 处差异

主文件第 7 节列了完整对照表。最要紧的三处：

- 四步的 `+` 改为串联 `→`，取 `min()` 而非求和
- 1,250 小时（知道）与 12,500 小时（会用）分开，不再混用
- SMART 的归属从德鲁克改回 George T. Doran（1981）

另外剔除了三个不能引用的数据：一万小时定律（Ericsson 本人否认该简化，且莫扎特 6 岁巡演）、721 法则作为时间分配（原为 70-20-10 领导力经验来源模型）、各年龄段专注分钟数（书中同页给出互相矛盾的两组数字）。
