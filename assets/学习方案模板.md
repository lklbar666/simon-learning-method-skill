
> 范围由目标倒推，不由知识体系倒推。按学科目录拆是最常见的错误。

### 切入点

选一个：

- ☐ 二分法（有清晰对立面：会/不会、必考/选考）
- ☐ 象限法（两个正交维度：重要×紧急、频次×难度）
- ☐ 进程法（有天然顺序：入门→进阶→实战）
- ☐ 组成法（可分解为部件：系统→模块→功能）

## 七、验真伪（S6）

### 三区定位

**我现在的难度在：**

- ☐ 舒适区（不费力，学的时候全程点头"说得对"）
- ☐ 成长区（有点难，够得着）
- ☐ 恐惧区（焦虑到看不进去）

若在舒适区 → 提高 20–30% 难度，或换更难的组块。
若在恐惧区 → 降难度，先补前置组块。

### 四档定位

- ☐ **记**：能背定义，套不进题
- ☐ **会**：能独立解出标准题，但慢、会错
- ☐ **熟**：不假思索能出手，能应付常规难度
- ☐ **巧**：一题多解、多题一解，能迁移到新场景

## 八、收敛判据

三条**同时**满足就停，不要追求 100%。

| 判据 | 阈值 | 我的实际 |
|---|---|---|
| 关键 20% 组块掌握率 | ≥ 0.9 | |
| 全部组块覆盖率 | ≥ 0.6 | |
| 陌生场景迁移成功次数 | ≥ 3 | |

**当前状态：** 达标 / 未达标

未达标时的顺序：**先补覆盖率**（边际收益最高）；关键 20% 不达标则不能往下走。
