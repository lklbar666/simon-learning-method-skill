# 01 · 公式与三要素

> 对应原书：前言、1.2 节、第 1 章、第 5 章开篇
> 本文解决一个问题：**`Fαt = MV` 这个从物理搬过来的公式，到底哪一项对应学习的哪个动作。**

---

## 一、广义动量定理逐项映射

原书前言把这个公式当作西蒙学习法的物理学底座：

```
F α t = M V
```

| 物理量 | 书中释义 | 学习中的对应 |
|---|---|---|
| `F` 力 | 不限于物理力，含体力、智力、想象力、忍耐力 | **投入的总能量**——注意力、认知资源、情绪能量 |
| `α` 方向 | 力朝向何处作用 | **学习领域的专一性**（锥尖朝向哪里） |
| `t` 时间 | 力在该方向上作用的时间 | **连续投入的时长**（不是累计时长） |
| `M` 质量 | 广义质量 | 承载成果的"体量" |
| `V` 速度 | 广义速度 | 推进的速率 |
| `MV` | 成果 | **学成之后你能做的事** |
| （隐藏变量）作用点 | 力具体作用在哪个位置 | **具体攻哪个组块 / 哪 20%** |

原书给了一个类比链，三组公式被它归为同构：

- 爱因斯坦：`成功 = 正确的方法 × 努力工作 × 少说废话`
- 稻盛和夫：`结果 = 思维方式 × 热情 × 能力`
- 西蒙：`学习 = 积极的学习动机 × 有效的学习方法 × 必要的时间投入`

**共同点**：都是乘法。乘法的含义是**任一项为零则整体为零**，且**低项对整体的拖累远大于高项的补偿**——把这个结构读懂，比记住任何一个公式都值。

### 作用点为什么是"隐藏变量"

这是全书最有洞察的一处，但原书只用了一句话带过。

`F`（努力）、`α`（方向）、`t`（时间）都是显性可感知的，人能自己评估"我努力了吗""我方向对吗""我花了多久"。但**"作用点"无法自省**——你没法从内部判断自己是不是攻在了关键那一小块上。

这解释了为什么很多人三要素都齐了还是学不出来：力足了、方向对了、时间够了，但**攻的是边缘组块**。刘谦和邢国芹的例子就是反面验证——他们的"作用点"选得极准（只攻这首曲子的按键动作），所以 3 周就出成果；而按正统路径从乐理开始学的人，作用点散在整个学科上，一年也未必弹得下来一首。

> **执行含义**：作用点必须**外部化**才能校准。做法是把它写下来（"这周攻组块 #17、#23、#31"），然后请人看，或者拿一个陌生场景试。留在脑子里的作用点等于没有作用点。

## 二、锥子模型

居里夫人的原话被原书用作核心比喻：

> "知识的专一性像锥尖，集中精力就像是锥子的作用力，时间的连续性就像不停地使锥子往前钻。"

三项逐一对应：

| 锥子 | 公式 | 反例 |
|---|---|---|
| 锥尖（专一性） | `α` | 什么都学一点 → 钝头，压强不够，钻不进去 |
| 锤击（集中精力） | `F` | 每天三心二意两小时 → 力散，打不进去 |
| 持续敲（时间连续性） | `t` | 周末一次学 15 小时 → 中间冷却，等同于反复熄火 |

**烧水的类比更直观**：持续加热，耗一定能量水就开了；加热一会儿熄火，耗能再多水也烧不开。原书用这个解释"为什么有人很努力却学不会"——不是能量不够，是**能量被中断损耗掉了**。

### 连续性的量级

书中没有给"连续"的量化标准。一个可用的经验判据（`[推测]`）：

> **单次学习间隔 ≤ 2 天。** 超过 2 天，上次建立的工作记忆基本清空，下次要从"重新进入状态"开始，实际有效时间打对折。

这与遗忘曲线的陡降段（1 天后剩 33.7%、2 天后 27.8%）在量级上吻合。

## 三、公式的结构缺陷与改写

原书 1.2 节的原文：

```
西蒙学习法 = 积极的学习动机 × (选择学习领域 + 设定学习目标 + 拆分学习内容 + 集中精力学习) × 必要的时间投入
```

### 缺陷

括号内四步用了 `+`。加法的语义是**可替代、可补偿**：做了拆分没做选择，靠拆分补上。

但四步的实际关系是**严格串联**：

```
选择领域 → 设定目标 → 拆分内容 → 集中精力
```

- 没有领域，目标无从设定（"3 个月学会 X"里的 X 就是领域）
- 没有目标，拆分没有边界（MECE 的第一步就是"明确范围"）
- 没有拆分，集中攻就没有对象（"集中精力"要集中到哪些组块上？）

串联结构的性质是 **`min(四步)` 决定上限**，不是求和。一个把四步都做了一半的人，有效值是一半的一半，不是"总分 50 分"。

### 改写

```
西蒙学习法 = 动机 × min(选择, 目标, 拆分, 集中) × 时间
```

**为什么这个改写重要**：它把"我该补哪一步"变成可判断的问题。按加法理解，人会倾向于补自己最擅长的那一步（通常是"拆分"，因为它看起来最有产出感——列清单、画导图）；按串联理解，正确做法是**先补最靠前的那一步空缺**。

实际观察到的失败模式高度一致：**跳过选择，直接在拆分和集中上做功**。表现是"每天学得很满，但说不出为什么学这些"。

## 四、三大要素逐项

### 4.1 动机：内驱 vs 外驱

原书 1.4 节用西蒙的成长经历做论证，核心结论是：

> "内在的学习动机比外在的学习动机更有效，也更持续。"

**证据**是高考后的大面积松懈——外部压力（家长、老师、考试）一撤，被动养成的学习行为立刻瓦解，严重到挂科退学。这证明的不是"这些人意志力差"，而是**外驱撑不起长期行为**。

原书给的动机来源清单（散在各节）：

| 来源 | 出处 | 特点 |
|---|---|---|
| 兴趣 / 好奇 | 1.4 西蒙的阅读史 | 最持久，可自发投入 |
| 意义感 | 2.2 黄金圈法则 | 强，但对抽象目标的人不起作用 |
| 情绪能量 | 5.6 王心仪《感谢贫穷》、作者的成长经历 | 极强，但来源不可复制（匮乏、不安全感） |
| 外部奖励 | 3.4 奖励杠杆 | 弱但可控，适合短期启动 |
| 公开承诺 | 3.4 读书沙龙案例 | 中等，靠社会压力 |
| 竞争 | 6.7 竞争学习法 | 中等，适合有同伴的场景 |

**黄金圈法则那条（2.2 节）值得单独说**：Wharton 呼叫中心实验——三组募捐员，只有"知道捐助对受助学生的价值"那组募捐额翻倍以上，而"知道对自己有好处"和"知道怎么打电话"两组都没变化。

> 这个实验的方法论问题见 `04` 事实核查。但结论方向可用：**"为什么做"比"怎么做"和"做了有什么好处"更能驱动行为。**

### 4.2 方法：四步

见 `02-六阶段操作手册.md`。此处只强调一点：**四步不是平行选项，是流水线。**

### 4.3 时间：必要投入

原书对"必要"的界定是：

> "学习必然需要时间的投入，需要大量实践和练习、大量试错和纠偏、大量反馈和调整，这样才能建立起有效解决同类问题的程序。"

关键词是**"程序"**——不是"信息"。这跟 1.3 节"学习不是记忆"是同一件事的两面。

时间量的估算见 `03-工时估算与量级对照.md`。这里只留一句：

> **"有时间"不等于"有时间块"。** 碎片时间可以用来复习（记忆卡片、断点续传），但不能用来建立程序——建立程序需要连续到能进入状态的长度，通常 ≥ 25 分钟。

## 五、什么是"真正的学习"（1.3 节）

原书在这里给了全书的认知地基，四点构成：

| 要素 | 作用 | 缺了会怎样 |
|---|---|---|
| **信息** | 基础 | 无米之炊 |
| **案例** | 信息的具象化，给出应用场景 | 知道定义，不知道什么时候用 |
| **练习** | 在大脑中建立程序 | 一看就会，一做就废 |
| **反馈** | 纠偏，重构程序 | 错误被固化 |

原书另给了一个"ABC 原理"（作者自创）：

```
看到 A → 记住 A → 只会用 A     （这是不会学习）
看到 A → 学到 B → 用出 C       （这才是学习）
```

B 是 A 背后的规律，C 是新场景下的应用。**从 A 到 B 需要归纳，从 B 到 C 需要迁移。** 记忆只完成 A。

### 与"知道≠做到"的区分

常听到的解释是"知道不等于做到"（知行合一问题）。原书的解释更准一层：

> "知道不等于学到。知道道理，只是以为自己学会了。"

区别在于：**"知道≠做到"把问题归到执行层，"知道≠学到"把问题归到认知层。** 前者暗示"我懂了但懒得做"，后者指出"你以为你懂了，其实没有"。

这个区分决定了纠正方式：前者靠加强执行（通常无效），后者靠检验理解（G6 的陌生场景测试）。

## 六、三要素的乘法效应：一个算例

假设三项各打 0–1 分（1 = 完全合格），整体成效 = 三项之积：

| 场景 | 动机 | 方法 | 时间 | 积 | 解读 |
|---|---|---|---|---|---|
| 热情高、方法错、时间足 | 0.9 | 0.3 | 0.9 | **0.243** | 最典型的"努力但学不出来" |
| 热情一般、方法对、时间足 | 0.6 | 0.9 | 0.9 | **0.486** | 比上一行好一倍 |
| 三项都中等 | 0.6 | 0.6 | 0.6 | **0.216** | 三项及格，总成效不如单项突出 |
| 三项都合格 | 0.8 | 0.8 | 0.8 | **0.512** | 没有短板才有高分 |

**这张表说明的事**：把 0.3 的方法修到 0.9，收益是从 0.243 到 0.486，翻倍。把 0.9 的动机提到 1.0，收益只有 11%。

> **执行含义**：三项里最该先修的是**最低那一项**，而它几乎总是"方法"（因为动机和时间是主观感受，人容易高估；方法是客观能力，人容易忽略）。

## 七、失效边界

这套公式在以下情形**不适用**，硬套会产生伪产出：

1. **纯事实性知识**（法规条文、API 签名、历史年份）。这类知识不需要"锥子"，只需要核对与检索。用组块模型算工时是浪费。
2. **已经会了的领域，只想补一个点**。四步流程对单点补充过重，直接用"找最佳实践 + 萃取动作"（3.2–3.3 节）即可。
3. **目标本身还没定**（"我该学什么"）。这时候 S1 的选择工具是唯一有用的部分，后面全部跳过。
4. **资源极度受限**（没有时间额度，也没有可支配的连续时段）。此时任何方法论都无效，先解决资源问题。

一个诚实的提醒：**这套方法的效能上限由输入质量决定，不由流程决定。** 用错误教材、跟错讲师、在错误的领域深耕，六阶段跑得再规范也得不到正确结果。原书 2.4 节"向头部、向有经验、向有成果的人学"这一条，权重比它看起来的位置高得多。
